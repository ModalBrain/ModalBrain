# ModalBrain Modular Patches & Devices 🎛️

This directory hosts community patches, Max for Live instruments/effects, and modular synthesizer patches for **VCV Rack** and **DISTRHO Cardinal**.

---

## 📂 Subdirectories

- **`m4l/`**: Max for Live devices (`.amxd`) for Ableton Live. Includes MIDI effects, scale quantizers, and audio resonators.
- **`vcv/`**: VCV Rack patches (`.vcv`) utilizing open-source modules from the VCV Library.
- **`cardinal/`**: DISTRHO Cardinal self-contained modular patches (`.vcv` / project states).

---

## 📋 Submission Guidelines

To ensure patches are reproducible and community-friendly:

1. **Module Manifest**: Include a companion markdown file with every `.vcv` or `.amxd` file detailing:
   - Required plugins / module brands (prefer open-source modules like Fundamental, Bogaudio, VCV, Befaco, Surge XT).
   - Audio input and pitch/gate CV routing diagrams.
2. **Audio Sample / Preview**: Include a short 10–30 second `.mp3` or `.ogg` audio demonstration preview (or YouTube / SoundCloud link).
3. **Screenshot**: Provide a clean screenshot of the patch front panel with visible cable routing.
